## 开工前必须先解决的两件事

### 1. Node 版本卡点（已实测）

`@angular/cli@22.2.6` 的 `engines` 要求 `^22.22.3 || ^24.15.0 || >=26.0.0`，本机 **24.14.1 会被拒（exit 3）**。两条路：

- 升级 Node 到 **24.22.2+**（24 系列当前最高）
- 或改用 **`@angular/cli@21.2.29`**（要求 `>=24.0.0`，实测 24.14.1 可通过）

### 2. 开发步骤文档需先校正

`03-Angular-开发步骤.md` 里仍有 **6 处已作废的取数假设**（`fetch` / `AbortController` / `validateHeroes` / 三态加载 / `?fail=1` / `cancelLoad`）。Vue 与 React 的最终实现都是**编译期 `import heroes.json`**，无请求可失败，Angular 必须按同一口径开工，否则会走一遍已知的返工。
