# 王者荣耀 · 英雄选择工具（AI 课程作业）

用**同一套英雄数据、同一套征召规则、同一套视觉样式**，分别用三种前端框架实现同一个「征召 BP 工作台」，用来对照三种框架在同一业务下的写法差异。

原型来源：课程给定原型（选人 / 海报 / 设置三屏）。全部实现围绕它展开，不改视觉基线。

---

## 分支约定

本仓库用**四个独立分支**对应课程的四个阶段，每个分支内容自成一体（orphan branch，互不继承）：

| 分支 | 课程 | 内容 | 状态 |
|---|---|---|---|
| **`main`** | 课程 1 | 原生 HTML / CSS / JS 静态版 + 全套素材 | ✅ 完成 |
| **`Vue3`** | 课程 2 | Vue 3 + Vite + Pinia + Router，选人 / 海报 / 设置三页 | ✅ 完成 |
| **`React`** | 课程 3 | React 19 + Vite，单页完整对局（Hooks + 内置 reducer） | ✅ 完成 |
| **`Angular`** | 课程 4 | Angular standalone + signal，单页对局 | ⏳ 未开工 |

切换分支即可看到对应阶段的完整可运行代码：

```bash
git switch Vue3     # 或 React / Angular
```

> 注意：`main` 是本仓库的默认分支，但**不是**其它三个分支的父提交。四个分支历史互不相关，这是刻意设计——课程各阶段是并列交付物，不是迭代关系。

## 本分支（课程 1）：原生静态版

不依赖任何框架与构建工具，直接打开 `index.html` 即可。

### 运行

```bash
# 方式一：直接双击 index.html（部分浏览器对本地文件有跨域限制）
# 方式二：起一个静态服务器（推荐）
npx serve .
# 或
python -m http.server 8000
```

### 关于素材

`images/` 是**三版共用**的源素材（133 位英雄的头像与封面，扩展名以 JSON 中的原名为准，存在 png 封面 3 张、`lanes` 为空 3 条）。

后续三个框架分支**不重复携带这份素材**，需要时从本分支取：

```bash
git show main:images/heroes.json > /tmp/heroes.json    # 单文件
git archive main images | tar -x                        # 整个目录
```

各框架分支的 README 里写明了具体的还原步骤。

## 征召规则（四个分支一致）

- 一局 20 步：先禁 10 位，再选 10 位，两方各禁 5、各选 5。
- 禁用顺序 F/S 交替；标准征召选人 `FSSFFSSFFS`；简单交替 `FSFSFSFSFS`。
- 单人视角：用户只占蓝方第 3 位（ban 第 4 步、pick 第 14 步），其余 18 步系统每 700 ms 代选一位。
- 两段式交互：先点卡=预选，再点同一张=确认落账。
- 我的 pick 落账后整池锁定。
- 只有我的 pick 步计时（默认 20 秒），超时从完整可用池随机。
- 搜索命中英雄名或称号，结果分三档（名字前缀 / 名字中间 / 仅称号），职业筛选为**单选**。
